SIGPIPE's default action terminates without a core, and this kernel
reports no fatal signals, so taking one is indistinguishable from a
clean exit. Nothing in doca/ or src/ calls exit(), _exit() or abort(),
and no Rust code calls process::exit -- the process has no way to end
itself deliberately. A Rust binary gets SIGPIPE ignored by the runtime
start-up its own main runs; the embedded proxy is a static library
linked into a C main, so that start-up never runs.
