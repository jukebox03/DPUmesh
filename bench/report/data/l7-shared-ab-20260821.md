# Shared per-workload Linkerd stacks — A/B receipts (2026-08-21)

Two full deploys of the same arrangement (`L7_BACKEND=linkerd`, byte bench via
`test-bench/echo-dpumesh`, framed `message`, N/K/A=32/8/4, `l7-worker=all`,
fail-closed), differing only in `DPUMESH_SHARED_STACKS` (→
`LINKERD2_PROXY_DMESH_SHARED_STACKS`). Suite:
`bench/suite/l7_session_cost.sh --reps 2 --dur 15`. Raw data and per-point logs
in `l7-shared-off-20260821/` and `l7-shared-on-20260821/`; every point carried
`fail=0 drops=0 reorder=0 worker_fail=0`.

- ARM cost per session, from the churn slope against each arm's own steady
  point: **OFF ≈ 3.9 ms, ON ≈ 0.4–0.5 ms (−87%)**.
- Under heavy churn the closed loop completes **4.4× more sessions** and
  **4.3× more requests**; the 30–40 ms p99 spikes (per-session stack build
  including control-plane fetches) disappear (p99 1.7 ms).
- The steady point is unchanged: the per-request data path does not know the
  stacks are shared.
